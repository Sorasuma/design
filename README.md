# Каталог фонов (Design Archive)

Статический сайт. Страницы: `index.html` (фоны), `headers.html`, `bots.html`, `medals.html`, `clones.html`, `statuses.html`, `hunt.html`. Общие файлы: `style.css`, `script.js`, `data.js`.
Изображения не хранятся в проекте — берутся напрямую по ссылкам из таблицы (raw.githubusercontent.com).

## Возможности
- Светлая и тёмная тема: кнопка справа вверху; по умолчанию берётся тема системы, выбор запоминается.
- Избранное (☆ на карточке, фильтр «Избранное») — хранится в браузере.
- В окне просмотра: стрелки ← → (и кнопки) — соседние позиции списка, «Копировать ссылку», «Открыть оригинал».
- Поиск и фильтры записываются в адрес страницы — ссылкой можно поделиться. Клавиша `/` — в поиск, `Esc` — очистить.

## Запуск локально
Откройте `index.html` двойным кликом или запустите `python3 -m http.server` и зайдите на http://localhost:8000.

## Обновление данных из таблицы
    pip install openpyxl
    python3 tools/build_data.py путь/к/таблице.xlsx
Скрипт перечитает названия и гиперссылки ячеек, перезапишет `data.js` и все `*.html` (по шаблону `tools/page.tpl.html`) и выведет отчёт
(позиции без файла, неполные строки, дубли). Лист «Костюмы не акт» пропускается намеренно.

## Автоподгрузка новых фонов (папка dop)
Страница «Фоны» при открытии смотрит папку из `config.js` (сейчас `Sorasuma/design`, ветка `main`, папка `dop`) через GitHub API (1 запрос, результат кэшируется на 3 минуты) и добавляет найденные файлы. Пересобирать сайт не нужно — достаточно загрузить файл в папку.
- Имя файла: `Название_сезон.расширение`, сезон — `зима`, `осень`, `весна`, `лето` или `общий_фон` (без суффикса тоже считается общим фоном). Пример: `Величавый_склон_осень.jpg`. Пробелы и подчёркивания при сопоставлении не важны, регистр тоже.
- Если название совпадает с актуальным фоном из таблицы — файл станет его новым сезоном. Если нет — появится новая карточка в локации «Новые фоны».
- Файл из папки **заменяет** вариант с тем же сезоном (из таблицы или `extra.json`); если такого сезона не было — добавляется новый. На карточке сразу показывается обновлённый вариант. Чтобы заменить картинку, достаточно загрузить файл с тем же именем поверх старого. Вложенные папки не читаются.
- Внизу страницы написано, сколько файлов подхвачено из папки; ссылка «Проверить заново» сбрасывает кэш. Если этой строки нет — на Pages лежит старая версия сайта.
- Лимит GitHub API — 60 запросов в час с одного IP; при ошибке сайт покажет предупреждение и продолжит работать на данных таблицы.

## Режим администратора (загрузка фонов прямо на сайте)
Страница `admin.html` (ссылка «Администратор» внизу каждой страницы) загружает изображения в папку из `config.js` через GitHub API — без сервера и пересборки. Загруженное видно всем посетителям.
1. Создайте токен: GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Repository access: *Only select repositories* → нужный репозиторий; Permissions → **Contents: Read and write**; срок действия — например, 90 дней.
2. Откройте `admin.html`, вставьте токен, нажмите «Проверить доступ».
3. Перетащите файлы, проверьте название и сезон (подсказки берутся из каталога), нажмите «Загрузить». Имя файла формируется само: `Название_сезон.расширение`.
4. Загрузка файла с тем же названием и сезоном заменяет прежний; если расширение другое (был .jpg, стал .png), старый файл удаляется автоматически. В блоке «Файлы в папке» файлы можно удалить.
Токен хранится только в браузере (по умолчанию до закрытия вкладки), отправляется только на api.github.com. Саму страницу может открыть любой, но без токена загрузить ничего нельзя. Токен никому не передавайте; если он попал в чужие руки — удалите его в настройках GitHub.

## Файлы, которых нет в таблице
Добавляйте их в `tools/extra.json` (page, name, label, url; для новой позиции — ещё section/group/location) и перезапускайте `build_data.py`: вариант присоединится к существующей позиции или создаст новую. Так добавлена осень «Величавого склона» (`dop/sklon1.jpg`) — после переименования файла в `Величавый_склон_осень.jpg` запись из `extra.json` можно удалить.

## Публикация на GitHub Pages
1. Создайте репозиторий (например, `design-catalog`), загрузите все файлы из этой папки в корень (включая `.nojekyll` и `data.js`).
2. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт откроется на https://ВАШ-ЛОГИН.github.io/design-catalog/
