Режим администратора

Загруженные здесь изображения сохраняются в и сразу доступны всем посетителям каталога (в течение пары минут).

1. Доступ

Как получить токен
  1. Войдите на GitHub под аккаунтом, у которого есть право записи в репозиторий (владелец или участник).
  2. Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → выберите репозиторий с папкой фонов.
  4. Permissions → Repository permissions → Contents: Read and write. Больше ничего не нужно.
  5. Срок действия — например, 90 дней. Скопируйте токен и вставьте выше. Никому его не отправляйте.

Токен хранится только в вашем браузере и отправляется только на api.github.com. Саму страницу может открыть любой, но без токена загрузить ничего нельзя.
